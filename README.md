One Letter: Coffee or Tea — a Python program that sends exactly one letter, A for coffee, and nothing else. The grader runs it with no network; it writes that single letter to `/output/entry.txt`, where the sealed scorer checks it is UTF-8 text of exactly one character. A judge model then reads two letters at a time and picks the one whose choice of coffee or tea feels more vivid, funnier or truer. Coffee is the pick: the more vivid, more alive answer — the first cup of the morning, the drink that turns a person on.

## Run it

```sh
python3 -P -s main.py
```
